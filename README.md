# Revision Reader

一个本地优先的“英语错句对照阅读器”。桌面端以 Original / Changed 左右并排阅读，手机端自动改为上下排列。

## 已包含

- 自动高亮原句中的错误/删除内容与改正句中的新增内容
- 支持“知识点”记录模式，内容可横跨 Original / Changed 两栏阅读
- 每组句子严格对应、共同滚动、长句自动换行
- 新增、编辑、删除、搜索、标签和日期排序
- 浏览器本地保存，刷新后仍保留
- JSON 数据导入与导出
- 六组示例数据
- 深色桌面阅读界面与手机响应式布局
- 复习模式：每轮最多 15 条，先隐藏改句和备注，自己回忆后再揭晓

## 复习模式

点击筛选栏中的「复习模式」，从当前搜索、复习进度和日期范围内的对照句中随机抽取，每次只显示一条。知识点和没有改句的记录不参加复习。

1. 先看 Original，尝试自己说出改句。
2. 点击「显示答案」，查看 Changed、差异高亮和备注。
3. 选择「会了」或「再练」，进入下一条。
4. 一轮结束后，可以重练没掌握的句子、继续下一组或结束复习。

「保存并退出」会保留当前句子、轮次、剩余队列和答案显示状态。关闭或重启软件后，点击「继续复习」即可接着练，继续时沿用上次的范围。「重新开始」会确认后替换复习位置；「结束复习」会清除本次位置，已保存的复习记录继续保留。

「撤销上一步」可退回最近一次选择，恢复该句原来的复习状态和时间，再次选择即可。轮末和进入下一轮后也能撤销，保存退出或重启后仍可用；最多撤销一步。编辑内容不会被撤销，已经删除或改为知识点的句子不会被恢复。

复习卡片右上角可直接编辑或删除。编辑保存后停留在当前句子，立即更新内容并保留原来的答案显示状态；删除需确认，确认后继续下一条并隐藏答案。改为知识点后会跳过该记录。删除的句子不会计为已会，也不会再进入重练队列。

选择下一组时，本轮需要再练的句子会保留在后续队列中。每次选择「会了」或「再练」，都会保存当前状态和上次复习时间，退出或重启后仍然保留；句子内容、备注和标签不受影响。

阅读卡片显示「未练过 / 需要再练 / 已会」和上次复习日期。筛选栏的「复习进度」可选择这三种状态，或选择「已练过」查看所有有记录的句子。已会的句子可以再次复习并改回需要再练。记录随 JSON 导入导出和桌面备份恢复保留。旧版未保存的复习历史无法补回，旧记录初始显示为未练过。

## 目录结构

- `app/`：网页应用界面与交互
- `desktop/`：Windows 桌面程序
- `web/`：网站部署所需的 Worker 与数据库示例
- `config/`：桌面打包和数据库配置
- `scripts/`：本地启动辅助脚本
- `build/`：构建与安装程序辅助文件
- `tests/`：自动检查
- `docs/`：设计与验收记录
- `public/`：公开静态资源

## 本地运行

1. 安装 Node.js 22 或更新版本。
2. 在此文件夹打开终端。
3. 首次运行：`npm install`
4. 启动应用：`npm run dev`
5. 打开终端中显示的本地地址，默认是 `http://localhost:3000/`

数据只保存在当前浏览器中。建议定期使用右上角的“导出备份”按钮保存 JSON 文件。

## Windows 桌面版

- 构建桌面页面：`npm run desktop:renderer`
- 打包 Windows 程序：`npm run desktop:package`
- 桌面版的数据保存在 Windows 独立用户目录 `%APPDATA%\Revision Reader`，不需要登录或服务器。
- 从 1.0 升级时，会把安装目录旁原有的 `data` 内容复制到新目录，旧数据不会被删除。
- 每次新增、编辑、删除或导入后都会静默更新最新恢复副本。
- 重新安装、覆盖更新和卸载时，安装程序会额外保留一份操作前备份；卸载不会删除个人数据目录。
- 如果浏览器本地存储损坏或丢失，桌面版会在下次启动时自动恢复最近的有效备份，不增加额外界面入口。
- 自动备份用于防止升级、覆盖安装和本地存储损坏；如需防范电脑或硬盘故障，仍建议定期导出 JSON 文件到其他位置。
- `outputs/`、本地安装目录、缓存和个人学习数据不会提交到 GitHub。
